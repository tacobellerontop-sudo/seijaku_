## What's changed in 0.2.0

- **Tabs close with a double-click.** The × on each tab is gone: double-click a tab to close it (Ctrl+W and middle-click still work). The strip is just words now.
- **The seal fits the strip.** The red seal in the top corner is now the same size as the tab words beside it, instead of looming over them.
- **Cheap motion.** The shell already composites on the GPU; new animations are opacity and transform only — tab colours and underlines fade, the home page rises slightly as it appears — so nothing reflows or costs real CPU.
- **One search line on the home page.** The home search is a single grey line that turns vermilion while you type; the second, always-grey line underneath it is gone, and so are the shortcut hints at the bottom (shortcuts themselves still work).
- **Custom themes.** Settings now has Ink, Paper, Matcha (dark green), Sakura (light pink), and Ai (dark indigo) — plus a Custom theme where you pick background, text, and accent colours. See `docs/THEMES.md` for the list and how to add one.
- **Search engine choice.** Settings now offers DuckDuckGo, Google, Bing, Brave, Startpage, Ecosia, Mojeek, and Qwant, or any custom engine URL with `%s` for the search. See `docs/SEARCH_ENGINES.md`.
- **Find and zoom, for free.** Ctrl+F finds in the page (Enter for next, Shift+Enter for previous, Esc to close); Ctrl+= / Ctrl+- zooms, Ctrl+0 resets. Both ride on the page itself, so they cost nothing when unused. Reopening a closed tab (Ctrl+Shift+T) was already there.
- **DRM kept on.** Encrypted video (Netflix and the like) stays enabled: the Widevine module still downloads on first use. One honest caveat — the engine binary is renamed, and that is untested against DRM sites, so if a DRM site refuses to play, the rename is the first suspect.
- **Extension filter, kept tiny.** Seijaku has no extension host, so an extension could never run here — direct loads of extension files are now refused with a plain explanation instead of pretending to install them.
- **Taskbar icon, properly fixed.** The button is grouped by AppUserModelID, not by the branding package or the icon file, so Seijaku now sets one stable ID (`Seijaku.Seijaku`) on its window and the installer puts the identical ID plus the seal icon on its shortcuts. If you pinned Seijaku before, unpin it and re-pin from the new shortcut — an old pin still points at the old grouping. The signed exe itself is untouched.
- **Default links actually open.** A link clicked elsewhere used to land on the home page because nothing in the shell ever read the launched address. The shell now reads it (from the window's arguments and the process command line, and from remote launches while it runs) and opens it as a tab, and the installer's open commands now use the `-osint -url "%1"` form. Deliberately not done: a registered command-line handler component, because registering one in the shipped, signed engine is unconfirmed — the window-side reading above cannot break startup, and it is what this release ships.
- **Popups open as tabs.** `window.open` used to do nothing because the shell gave Gecko nowhere to put the new window. The shell now provides that hook and maps every popup onto a tab, returning the tab's window so the opener works. The popup blocker itself stays on — clicked popups work, drive-by popups still don't.
- **Camera, microphone and notifications, on a switch.** A real prompt UI (with device choice) still needs a registration step that is unconfirmed for the shipped engine, so until that exists Settings has a plain switch: on, sites get camera, microphone and notification access at once, with no prompt. It is off by default, and location is not on it — location still needs a real prompt.
- **Auto-hide chrome, on a switch.** The title bar, tab strip and address line collapse away and only a thin red line stays at the very top edge. Move the mouse to that edge to bring the bars back; moving onto the page hides them again. Ctrl+Shift+H flips the setting, so the mode can always be left from the keyboard.
- **Top address bar, centred and smaller.** It now sits in the middle of the toolbar at 480px wide instead of stretching edge to edge, with the lock icon attached to its left; the nav buttons stay left and the menu stays right, and it shrinks on narrow windows instead of overlapping them.

Install with `SeijakuSetup-0.2.0.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.

Honest caveat for the three fixes above: they are all written defensively (every new call is guarded, so a missing piece in the shipped engine leaves the old behaviour instead of breaking the shell), but none of them can be proven without a Windows run. The taskbar grouping, a clicked http link, a popup, and the permission switch are the four things to try first on 0.2.0.
