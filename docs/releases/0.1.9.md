## What's changed in 0.1.9

- **Tabs fit their names.** Tabs used to stretch equally to fill the whole strip, so a short title sat in a wide tab. Now each tab is only as wide as its title (plus padding), and the + button sits right after the last tab. When the strip runs out of room, tabs shrink and long titles truncate with an ellipsis at 240px, as before.

Install with `SeijakuSetup-0.1.9.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
