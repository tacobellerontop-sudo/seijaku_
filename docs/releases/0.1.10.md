## What's changed in 0.1.10

- **Better arrows.** The back, forward, reload and menu buttons now draw their symbols from Segoe UI Symbol instead of the UI font, so the arrows look like proper symbols instead of thin, uneven characters. The symbols themselves are unchanged.
- **The address bar is underlined.** It used to float as plain text in its row; it now has a vermilion hairline under it, matching the home page's search underline, so it reads as a field you type into.

Install with `SeijakuSetup-0.1.10.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
