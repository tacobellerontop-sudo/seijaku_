# Seijaku 0.2.13

Everyday things that a browser is expected to do, and Seijaku didn't: these were all handled by the part of Firefox that Seijaku leaves out. Each one only wakes on its own click or key, so a running page costs nothing extra.

## Right-click menus

- **On a page:** back, forward, reload, bookmark, save page, print, reader view, select all and view page source.
- **On a link:** open in a new tab, open in a private window, copy the address (or the email address for a mail link) and save the link.
- **On an image:** open in a new tab, copy the image, copy its address and save it.
- **On a video or audio file:** open, copy the address and save.
- **In a text box:** undo, cut, copy, paste, delete and select all.
- **On selected text:** copy, and search for it with your search engine.
- **On a tab:** reload, duplicate, pin, mute, sleep, copy the address, close, close other tabs, close tabs to the right and reopen a closed tab.

A site that draws its own right-click menu (a web app or a game) keeps it.

The menu uses the theme's colours, like the floating address bar.

## Choose the strip's buttons

Right-click the strip (anywhere but a tab) to turn each button on or off, or use the new **Strip buttons** section in Settings. There are four new buttons that start off: Home, Reader view, Bookmarks and History. Keyboard shortcuts keep working for buttons you hide.

## Links and the mouse

- **Middle-click or Ctrl+click a link** to open it in a new tab behind the current one. Add Shift to switch to it, or Shift+click alone. Several links opened from one page stay in order, right after it.
- **The mouse's back and forward buttons** go back and forward. Keyboard media keys for home, search, print and the like work too.

## Video full screen

A video's full-screen button (YouTube and the like) now fills the screen. A short note says which site is full screen and that Esc leaves. Switching tabs also leaves full screen.

## Keys

- **Ctrl+Shift+R** or **Ctrl+F5** reloads without the cache.
- **Alt+Home** goes to the home page.
- **Ctrl+S** saves the page. It saves the page's file as the site sends it (its HTML, a PDF or an image), not a copy of everything the page loaded. Web editors that use Ctrl+S themselves still get it first.

## Not in this release

Most extensions need APIs for tabs, windows and toolbar buttons that come from the same left-out part of Firefox. That is a separate piece of work.
