## What's changed in 0.1.6

- **Auto-update.** Seijaku now checks GitHub for a new release when it starts, at most once a day (turn it off in Settings). If one is out, the message line says so, and typing `:update` downloads the installer, closes Seijaku, installs silently, and starts Seijaku again — no trip to the releases page. If anything in that chain fails, it opens the release page instead of leaving you stuck. The portable build can't install over itself, so on portable it just opens the release page for the new zip.

Install with `SeijakuSetup-0.1.6.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
