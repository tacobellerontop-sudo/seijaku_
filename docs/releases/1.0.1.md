# Seijaku 1.0.1

## Extension popup windows

When an extension opens a window of its own, such as Bitwarden's passkey prompt, it now gets a small separate window: just the extension's page, with no tab strip and no window frame.

Before this, the prompt opened as a tab in your main window, and when the extension closed it, your whole window closed with it. Now only the popup window closes.

Links you open from a popup window open as tabs in your main window. A popup window doesn't save anything: no history, no session, and it doesn't change your main window's size.
