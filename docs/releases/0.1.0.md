What's new in 0.1.0: Seijaku, first release.

- **A quiet, light browser on Gecko.** One tab strip, one address line, one page. Tabs fall asleep after 15 idle minutes, and only the selected tab loads at start.
- **A dark, minimal new tab page.** A wordmark, a search underline, and nothing else. No pinned sites, no most-visited tiles, no boxes.
- **Mozilla's services stripped.** No telemetry, no studies, no Pocket, no sponsored content, no accounts, no sync, no crash uploads. See docs/STRIPPED.md for the full list, including the one trade-off: Safe Browsing is off.

Install with **SeijakuSetup-0.1.0.exe** (no admin rights, no Firefox needed first), or unzip **Seijaku-0.1.0-win64-portable.zip** and run Seijaku.bat (the profile stays in the profile folder next to it).
