# Seijaku 1.0.6

## Open PDFs and web pages from Windows

Choosing Seijaku under "Open with" for a PDF now opens it in a tab. So does making Seijaku the default app for PDFs, which you can now pick in Windows' Default apps settings.

Before this, Seijaku didn't start at all when Windows handed it a file. The same problem stopped links from other apps opening in Seijaku when it was your default browser. Seijaku's open commands passed their options in an order the engine refuses, so it quit straight away. Updating to 1.0.6 rewrites those commands.

If Seijaku is already running, the file or link now opens as a new tab in that window. Before, the window only came to the front.
