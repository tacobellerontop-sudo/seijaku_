# Seijaku 0.2.8

## Fixed: Update button on installed builds

Settings "Update Seijaku now" no longer mistakes a genuine install for a
portable build. The installed check now looks for the install's uninstall
registry entry as well as `unins000.exe` next to the app, so it works even
when the file check alone misfires. Portable builds (no install, no
uninstaller) still open the release page as before.

## Navigation buttons now use Material Icons

Back, forward, reload, and the stop state render from the Material Icons
font — bundled with the browser, so it works offline — matching the bold
toolbar icons of other browsers. The old thin arrows are gone. Nothing else
in the strip changed: same button boxes, same layout, same other icons.

## Test on Windows

- Nav buttons (back, forward, reload, stop) render bold and instantly on
  startup, with no fallback flash or blank boxes.
- Stop shows as a solid square on slow loads and flips back to refresh.
- Installed build: Settings → Update Seijaku now downloads the installer
  and installs on quit.
- Portable build with no install: Update still opens the release page.
