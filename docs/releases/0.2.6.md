## What's changed in 0.2.6

One fix, for a bug 0.2.3 introduced: the settings dropdowns opened but wouldn't let you pick anything.

- **Dropdown options now select on mouse-press, not mouse-release.** The old code listened for a click on each option, but the button's blur handler hid the list on a timer first — the timer fired between pressing down and letting go, so the option was gone before the click could land and nothing got picked. Selecting on press (and keeping focus on the button while it happens) removes the race entirely: the pick lands in the same instant as the press, the setting applies, the list closes. Keyboard selection, clicking outside to dismiss, and tabbing away all still work as before.
- Same fix covers the bookmarks and PDF pages, since all three share the one dropdown component.

Install with `SeijakuSetup-0.2.6.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.

Honest caveat: the fix itself hasn't run on Windows yet. The test is: click an option on Settings, bookmarks, and the PDF page — value changes, button label updates, list closes — plus keyboard selection still working.
