# Seijaku 1.0.10

## Camera, microphone and screen sharing work in video calls

Zoom, Meet, Teams and other call sites can now use your camera. Before, Seijaku showed its prompt and you could press Allow, but a real webcam still refused to start: the engine wanted one more go-ahead that only Firefox's own interface used to give. Seijaku now gives it whenever you allow the camera.

- Camera and microphone are asked in one prompt instead of two. If you have more than one camera or microphone (a laptop camera and a USB one, say), the prompt lists them so you can pick.
- Once you allow a site, it isn't asked again in that tab for an hour, so a call site that asks several times (preview, join, switching cameras) doesn't keep prompting. Tick "Remember this decision" to allow it for good.
- Screen sharing works. When a site asks to share your screen, the prompt lists your screens and windows and you pick what to share. It is asked every time and never remembered.
- The prompt now waits for an answer: clicking the page no longer counts as Block.
