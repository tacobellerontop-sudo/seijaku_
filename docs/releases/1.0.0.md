# Seijaku 1.0.0

Extensions work. With this, Seijaku covers what you need from a browser day to day: tabs, history, bookmarks, private windows, reader view, right-click menus, downloads, and now your add-ons.

## Extensions

- **Install from addons.mozilla.org.** Open the site from **Extensions › Get extensions…** and press "Add to Firefox". Seijaku asks first and lists what the extension will be able to do. Installs from other sites ask whether you trust the site.
- **Each extension gets a button in the strip**, with its icon and badge (uBlock Origin's blocked count, for example). Click it to open the extension's popup.
- **Extensions can work with tabs and windows**: open, close, move, reload and switch tabs, and run their scripts in pages. A sleeping tab counts as a discarded tab, so extensions don't wake it.
- **Extensions page:** an Options button for extensions that have settings, and the list updates as soon as you add or remove something.
- Extensions must be signed by Mozilla, as in Firefox. They update daily from addons.mozilla.org.

uBlock Origin was tested end to end: it installs from the site, blocks ads and shows its popup.

The popup and the extension's background page run in their own extension process. Nothing extra runs until you install an extension.

## Not yet supported

Some extension features come from parts of Firefox that Seijaku still leaves out: right-click menu entries added by extensions, extension keyboard shortcuts, sidebars, and buttons in the address bar. Extensions that use them still install and run, but those features do nothing.
