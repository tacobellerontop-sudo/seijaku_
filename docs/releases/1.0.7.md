# Seijaku 1.0.7

## Bookmarks that work

The row under the home page's search box now shows your bookmarks, so a page you star appears there straight away. Its + button opens a small form: type an address (and a name if you like) and it is added to the row. Hover over a shortcut and press × to remove it.

The bookmarks page and the home page now update as soon as you bookmark something in another tab. Before, an open bookmarks page kept saying "No bookmarks yet" until you reloaded it. Seijaku's own pages (home, settings and the like) can no longer be bookmarked by accident.

## The address bar only on Ctrl+L

A new tab (Ctrl+T or the + on the strip) opens the home page with the caret in its search box. The floating address bar no longer pops up over it. Ctrl+L still brings the bar up on any tab. If your home page is set to another address, Ctrl+T keeps opening the bar, since there is no search box to type in.

## Settings

Settings has a row of sections at the top (General, Strip, Privacy, Downloads, Video, Weather, Updates, Shortcuts). Click one to jump to it. The row stays at the top while you scroll and marks where you are.

A new Updates section shows exactly which version of Seijaku you are on, and the Firefox engine version under it, next to the update switch and the Update now button.
