## What's changed in 0.1.8

- **Cleanup, no new features.** An audit of the whole repo found the code itself was already tight — every function, setting, stylesheet rule and installer entry is used — so this release takes out what was actually dead: two theme colours (`--tab`, `--tab-selected`) that were set but never read, since tabs are words, not boxes. The rest is stale writing: the README and plan still described 0.1.0 as an unreleased scaffold, said four settings, and pointed at a version that no longer exists. They now describe the browser as it is: compact chrome, tab sleeping, lazy restore, auto-update, and no command bar.

Install with `SeijakuSetup-0.1.8.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
