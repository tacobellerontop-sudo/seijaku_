## What's changed in 0.2.2

This one is a bigger step: the chrome gets out of the way, and the browser gains the pieces the sketch asked for. Two batches in one release — the minimal-UI rework first, then everything from the sketch. As before, your data stays in one small file in your profile — no accounts, no sync, nothing sent anywhere, except the weather widget, which asks Open-Meteo for the forecast (see below).

- **A floating address bar, and nothing else.** The persistent address bar is gone. Press Ctrl+T for a new tab or Ctrl+L on the current one and a bar floats centred over the page: type a URL or a search, and it suggests your open tabs first, then bookmarks, then history. Arrows move, Enter opens (or switches to the tab), Esc closes. It's a real panel above the page, not a box that can paint underneath it. Copy-URL and Reader buttons sit in the bar; back, forward, the star, and the menu moved into the tab strip.
- **Tabs on any edge.** The strip can sit on the top, bottom, left, or right — a dropdown in Settings picks. Side strips are vertical with full titles; the seal and nav sit on top, actions at the bottom.
- **Hidden chrome that actually reveals.** The old hover reveal never worked: the edge line lived inside the hidden chrome, so it could never catch a hover. Now a hit-testable strip sits outside the hidden chrome at whichever edge the tabs are on — hover it and the chrome comes back. Ctrl+Shift+H still toggles it.
- **The command bar stays gone.** The tree was grepped for remnants and there were none to remove — and the new palette below is not it.
- **Sleep a tab on demand.** Ctrl+Shift+S sleeps the current tab right now. The 15-minute auto-sleep is unchanged.
- **A PDF viewer that annotates.** Typed or bookmarked PDF links open in the built-in viewer: page navigation, zoom, freehand ink in five colours and three widths, text notes, and Save writes an annotated copy to Downloads. (Clicking a PDF link inside a page still downloads it — only shell-initiated navigations route to the viewer.)
- **Permission prompts, properly.** When a site asks for camera, microphone, or notifications, a panel appears at the top of the window with the site, the request, Allow/Block, and a remember choice. A lock mark in the strip shows a site you've already granted; click it to revoke. The Settings switch still overrides everything, and location stays denied.
- **Private windows.** Ctrl+Shift+N opens one, with a Private badge, no history, no session save or restore, and its own downloads list. Bookmarks are shared, the way Firefox does it.
- **Extensions.** The extensions page lists what's installed, with enable, disable, remove, and install from a .xpi file. Extension buttons appear in the tab strip. Chrome-format (.crx) files still can't run in Gecko and are refused with the reason.
- **Reader view, tab mute, and the small things.** Reader view cleans an article for reading (button in the floating bar), audible tabs show a speaker mark you can click to mute, the Settings page lists every shortcut, and view-source: addresses open.
- **Stop, and a loading mark.** The reload button becomes stop while a page loads, and loading tabs dim with a pulsing dot.
- **Bookmarks grow up.** Search within bookmarks, import from a file (HTML, Chromium JSON, or Seijaku JSON) or straight from a Chrome, Edge, or Brave profile — duplicates skipped, nothing wiped — and export to HTML or JSON. Bookmarks now have folders: All, Reading list, Frequent, and your own.
- **A real HTTPS indicator.** Separate from the permission lock: a lock mark for secure sites, a warning otherwise, hidden on internal pages. Click it for the site's info — host, connection state in plain words, its permissions with Revoke, and a shortcut to Settings.
- **Privacy settings.** Tracking protection (Strict, Standard, Off) in a new Privacy section — Strict is the default, because the browser already shipped the strict bundle and Standard would have silently weakened it — plus clear browsing data (history, cookies, cache, downloads), with the warning that clearing cookies signs you out of sites.
- **Fonts, startup, System theme.** Page font family and size in Settings, a startup choice (restore session, home, or blank), and a System theme that follows the OS dark/light setting live.
- **Pinned tabs.** Ctrl+Shift+P pins the current tab: pinned first, narrow with a vermilion dot, never sleeps, and refuses every close until unpinned. Pins survive restart.
- **A home page from the sketch.** Time-based greeting with Japanese, "THE WEB CAN WAIT", a FREQUENT row drawn from your Frequent folder (never from history — the home page still refuses to query history on every new tab), Tabs/Bookmarks/History/Settings counts, red-moon art redrawn in the dot-art style, and a weather widget (Open-Meteo, Singapore by default, city and off switch in Settings).
- **Command palette.** Ctrl+K opens a searchable panel of commands, open tabs, and bookmarks — new tab, private window, settings, themes, sleep, mute, reader, and the rest. Arrows, Enter, Esc. It is a pick-from list, not the old `:` bar, and none of that code came back.

Install with `SeijakuSetup-0.2.2.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.

Honest caveat: none of this has run on Windows yet, and two pieces can only be proven there. Extensions first: does a real .xpi (uBlock Origin is the test) install, block, and show its strip button, and does startup stay clean with extensions installed? Then permission prompts: if a camera test page never shows the panel, the engine isn't routing through the prompt component, and the Settings switch is the working fallback — say so and it gets fixed. After those: private windows (badge, no history, main session intact, clicked links opening in main only), PDF save (ink surviving zoom, the annotated file opening elsewhere), the floating bar and palette painting above real page content, autohide on all four edges, home weather failing gracefully with networking off, and import keeping folders intact with duplicates skipped. Everything is written defensively, so a missing engine piece leaves the old behaviour instead of breaking the shell.
