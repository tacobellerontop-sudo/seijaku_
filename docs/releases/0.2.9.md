# Seijaku 0.2.9

## Fixed: Update downloads failing with "Not enough arguments"

Pressing Settings "Update Seijaku now" on an installed build failed with
"Update failed: Not enough arguments [nsIWebBrowserPersist.saveURI]" and
fell back to opening the release page. The download helper was calling the
engine's file-download function with 7 arguments; current Gecko requires
10, including a triggering principal and the target file as a file URI.
The call now passes all 10, matching Firefox's own code. The same helper
also serves extension installs from a URL, so those are repaired too.

## Test on Windows

- Installed build: Settings → Update Seijaku now downloads the installer,
  installs on quit, and restarts on the new build.
- Extension install from a URL works.
- Portable build with no install: Update still opens the release page.
