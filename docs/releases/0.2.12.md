# Seijaku 0.2.12

A look-and-feel release. Seijaku looks the same (ink, one vermilion accent, words instead of boxes) but is more refined. One small fix.

## One set of icons

Every button on the strip is now drawn from one set of thin line icons: back, forward, reload, stop, new tab, reopen, bookmark, downloads, the locks and the menu. They share one weight and take the theme's colours. Before, some came from a bundled icon font and others from Windows' symbol font, so they didn't match. The icon font is gone.

## A calmer strip

- The strip is one even 36px row. Buttons are a little larger, and a faint wash shows on hover instead of only a colour change.
- While the selected tab loads, a short vermilion line drifts along the strip's edge. If Windows animations are turned off, it shows as a still line.
- The selected tab's underline grows from the centre. On a side strip, the selected tab gets a soft highlight with the vermilion edge.

## Floating panels that float

The floating address bar, the command palette, the permission prompt and site information were drawn on the engine's default grey box. They now use the theme's own colours, with small rounded corners and a soft shadow. A picked suggestion is a faint vermilion tint with a short edge, not a solid red block.

## Pages

Settings, bookmarks, history, downloads and extensions get rounded controls, a vermilion mark under the page title, and hairlines between sections. List rows highlight on hover, and setting labels are quieter, so the values stand out.

## Fixed

- Home and the other built-in pages showed the "not secure" mark on the strip. The engine's security report for those pages overwrote their neutral state.
