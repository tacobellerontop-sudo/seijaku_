# Seijaku 1.0.9

## Private windows look different

A private window no longer looks like an ordinary one. It always has its own deep plum colours with a violet accent, whatever theme you picked, and so do the home page, settings and Seijaku's other pages inside it. The strip has a violet line along its edge, and a solid "Private" mark with a mask sits next to the window buttons.

Ordinary windows keep your theme as before.
