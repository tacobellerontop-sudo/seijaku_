## What's changed in 0.1.2

This one is about the feeling, after the 0.1.1 fixes landed. 0.1.1 made the chrome warmer, but the home page still glowed like a generic dark theme — gradients, a fading horizon, a ghost of a kanji. That is not Ryoku.

- **No gradients, anywhere.** The home page background and the horizon line are flat now. The feeling has to come from drawn things, not shaded ones.
- **Dot art.** A faint dot field covers the home page, and on the right a rising-sun disc made of vermilion dots sits inside a thin abstract circle, half off the edge, with plus marks — the same language as Ryoku's dithered statue and thin circle.
- **Kanji, present.** 静寂 is no longer a faint ghost on the right. It stands vertically on the left, in muted warm grey, where you can actually read it.
- **Formal matched with casual.** The wordmark is a large formal serif now, the gloss under it is serif italic ("for the sake of silence"), and the footer hints are tiny uppercase tracked labels, like Ryoku's nav. The centred search from your sketch stays exactly where it was.
- **Solid hairlines.** The tab and address rows are divided by one solid thin line each, not a translucent blend.
- **Taskbar icon, properly this time.** 0.1.1's launcher stamping didn't take — the icon was still Firefox's in the 0.1.1 build. This uses Breached's method instead: Gecko itself loads the window icon from `chrome/icons/default/seijaku-window.ico`, drawn at build time with the same seal, so the taskbar and Alt+Tab show Seijaku because the window itself carries the icon, not because a launcher raced to stamp it on afterwards. The launcher stamping stays as a backup.

Install with `SeijakuSetup-0.1.2.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
