## What's changed in 0.1.7

- **The command bar is gone.** No more `:` line, no `:open`, `:tab`, `:close`, `:sleep`, `:help`, or any of the rest — everything they did is already on the keyboard (`Ctrl+T`, `Ctrl+W`, `Ctrl+L`, `Ctrl+,`) or automatic (idle tabs sleep on their own). The unused launcher left over from Breached is gone too. What remains is tabs, an address line, settings, and the message line.
- **Auto-update without commands.** The startup check still runs (at most once a day, if enabled in Settings): a newer release now downloads in the background and installs when you quit Seijaku, with no step to remember. Settings also has an Update button that checks and installs immediately. The portable build still just opens the release page, since it has no installer to run.

Install with `SeijakuSetup-0.1.7.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
