# Seijaku 1.0.3

## Sign-in buttons and new-window links work again

Clicking a link or button that opens a new window now does what it should. That covers "Sign in with Google", logins such as Anthropic's, and links set to open in a new tab. Before this, the click did nothing and the only way through was right-click, Open link in new tab.

The new page opens as a tab right next to the page it came from. It stays connected to that page, so a sign-in window can hand its result back and finish the login. When it closes itself, its tab closes and you're back on the page you started from. Neither tab is put to sleep while the two are connected.
