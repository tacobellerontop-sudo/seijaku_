# Seijaku 0.2.7

## Fixed: Update button on installed builds

Settings "Update Seijaku now" no longer mistakes a genuine install for a
portable build. The installed check now looks for the install's uninstall
registry entry as well as `unins000.exe` next to the app, so it works even
when the file check alone misfires. Portable builds (no install, no
uninstaller) still open the release page as before.

## Navigation buttons now use Segoe Fluent Icons

Back, forward, reload, and the stop state render from Segoe Fluent Icons —
the same system font the window buttons already use — instead of the old
Segoe UI Symbol arrows. Crisp at 16px, already loaded in the window, so
refresh no longer pops in late. Other strip icons (star, downloads, lock,
menu) are unchanged.

## Test on Windows

- Installed build: Settings → Update Seijaku now downloads the installer
  and installs on quit.
- Nav buttons (back, forward, reload, stop) render instantly on startup
  with no fallback flash.
- Portable build with no install: Update still opens the release page.
