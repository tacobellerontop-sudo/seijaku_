## What's changed in 0.1.5

- **Compact chrome.** The top of the window is now 56px tall instead of 74px: the titlebar/tab row went from 38px to 28px, the address line from 36px to 28px, and the seal, tab padding, window buttons and navigation buttons all shrank to match (12px type instead of 13px, 24px nav buttons instead of 30px). The bottom message/command line is 20px instead of 24px. Nothing else changed — same tabs, same address line, same home page, just more of the window left for the page itself.

Install with `SeijakuSetup-0.1.5.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
