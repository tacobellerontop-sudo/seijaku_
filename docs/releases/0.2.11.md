# Seijaku 0.2.11

A one-fix release for in-app updates.

## Fixed: Update left a terminal open and never installed

Pressing **Update** (or quitting with an update downloaded) closed Seijaku and opened a terminal window that never went away. The update never installed. The updater waited until no program named `firefox.exe` was running anywhere on the PC, so a regular Firefox left open, or any leftover Firefox process, kept it waiting forever.

The updater now:

- runs hidden, so no terminal window appears
- waits only for Seijaku's own processes, and ends any that are still running a minute after you quit
- installs silently, then starts Seijaku again by itself
- writes the installer's log to `%TEMP%\seijaku-update.log` and cleans up after itself

A new Windows test runs a real update with another `firefox.exe` open, and it now runs on every change.

**Updating from 0.2.10:** 0.2.10 still has the old updater, so install this version by hand from the installer below. You can also close any other Firefox windows before you press Update. Later updates install by themselves.
