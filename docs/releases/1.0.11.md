# Seijaku 1.0.11

## Saving and printing work again

- **Save as works.** Saving a PDF from the viewer (its Download button or Ctrl+S), and every other "Save … as" (links, images, videos, pages), stopped with "Couldn't save that: … nsIFilePicker.defaultString". The Windows save dialog now opens with the file's name filled in, and the file is saved.
- **Printing works.** The PDF viewer's Print button, and Print buttons on web pages, failed or left a blank tab. They now open the Windows print dialog and print. Ctrl+P no longer flashes an extra tab while it prints.
