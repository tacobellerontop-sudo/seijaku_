# Seijaku 1.0.5

## Updates install on their own, with no permission prompt

Seijaku now runs the new version's installer directly when it updates, the same way Breached does. Before this, it went through a small script, and Windows could stop to ask whether that script was allowed to run. Now nothing asks: press Update in Settings, or just close Seijaku after it has downloaded an update in the background, and it installs quietly and opens again by itself.

The installer waits for Seijaku to close before replacing its files, and a Firefox you have open is left alone. The downloaded installer is tidied out of your Temp folder the next time Seijaku starts.

If you are on 1.0.3 or 1.0.4, the update to this version still goes through the old script one last time, so Windows may ask once more. Every update after that installs without asking.
