## What's changed in 0.1.4

This one mirrors Breached, after a line-by-line diff of the two repos for the taskbar icon — 0.1.3's icon file and `icon` attribute still showed Firefox, so the difference had to be elsewhere. Two real differences were found:

- **A branding package, which Seijaku didn't have.** Breached registers `chrome/branding` (brand.properties) and its localization, naming the app Breached throughout Gecko's own dialogs and identity. Seijaku had no branding at all, so Gecko fell back to Firefox's identity wherever it needed one — which is consistent with Windows treating the window as Firefox's. Seijaku now has the same branding package, naming it Seijaku.
- **The full icon size set.** Breached's icon has 9 sizes (16, 20, 24, 32, 40, 48, 64, 128, 256); Seijaku's generated icon had 6 and was missing 20, 24 and 40 — and the Windows taskbar asks for 24. The generated icon now has Breached's exact set.

Everything else icon-related is unchanged: the window icon file in `chrome/icons/default/`, the `icon` attribute, the renamed `seijaku.exe` process, and shortcuts that pass `-app`.

Install with `SeijakuSetup-0.1.4.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
