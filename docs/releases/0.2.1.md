## What's changed in 0.2.1

This one adds the pieces a browser needs before it can really be called a browser. Everything below is stored in one small file in your profile, alongside the session file — only your real bookmarks and visits, no accounts, no sync, nothing sent anywhere.

- **Bookmarks.** The star button next to the menu saves the current page (Ctrl+D does the same); Ctrl+Shift+B opens the manager page, where you can open a bookmark in a tab or remove it. The star fills in when the open page is already saved.
- **History you can browse.** Every real visit is recorded — internal pages never are, and visiting the same page twice in a row counts once. Ctrl+H opens the history page, newest first, with search; click an entry to open it, or clear the whole history from the page.
- **Downloads you can see.** Ctrl+J opens the downloads page, which lists the engine's own downloads: name, state, progress, and sizes, with Cancel, Open, Show in folder, and Remove from list. If the engine's download list isn't there in the shipped build, the page says so plainly instead of showing an empty list — files still land in your download folder either way.
- **Reopen a closed tab, with a button.** Ctrl+Shift+T already worked; now there is also a ↩ button after the + button in the tab strip. It is greyed out when there is nothing to reopen.
- **Address bar suggestions.** Type two or more characters and a dropdown offers your bookmarks first, then history, newest first, up to eight. Arrow keys move through them, Enter opens the highlighted one, Esc closes the list. It only ever suggests from your own data — nothing is fetched and nothing goes to the network.

Install with `SeijakuSetup-0.2.1.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.

Honest caveat: like the 0.2.0 fixes, all five features are written defensively (every new call is guarded, so a missing piece in the shipped engine leaves the old behaviour instead of breaking the shell), but none of them can be proven without a Windows run. Try the suggestion dropdown first — if it paints underneath page content in the shipped engine, it needs to become a proper panel instead of a plain box, and typing plus Enter still work either way. Then the downloads list, bookmarks and history surviving a restart, the star following tab switches, and the reopen button's enabled state.
