## What's fixed in 0.1.1

- **One title bar, not two.** 0.1.0 drew the Windows title bar above Seijaku's own one. The window now tells Gecko it has a custom title bar, so only Seijaku's remains — and it now holds the tabs too, so the whole chrome is two quiet rows: tabs, then the address line.
- **The taskbar icon is the seal.** The running browser used to show Firefox's icon, because the window belongs to firefox.exe. The launcher now stamps the vermilion seal onto the browser's windows, so the taskbar, Alt+Tab and the window switcher all show Seijaku. Start menu and pinned shortcuts already did.
- **More Japanese, less generic-dark.** Warm sumi ink instead of cold blue-grey, Yu Gothic for the interface and Yu Mincho serif for kanji, and the home page now carries the name's own kanji — 静寂 (silence, stillness) — written vertically down the right side, with its meaning under the wordmark.

Install with `SeijakuSetup-0.1.1.exe` (no admin, no Firefox first), or unzip the portable build and run `Seijaku.bat`. The files aren't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" — choose More info, then Run anyway.
