extensions

Extensions run in Seijaku now. Install .xpi files (the Firefox format) with the button below. .crx files (the Chrome format) are NOT supported, because they cannot run in Gecko — that refusal is deliberate, not a bug. An extension with a toolbar button shows its button in the tab strip (the shell renders it). Extension behaviour can only be fully proven on Windows.
