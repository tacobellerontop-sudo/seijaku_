extensions

Seijaku runs Firefox extensions. Get them from addons.mozilla.org (Add to Firefox works here), or install a .xpi file below. Every install shows what the extension will be able to do and asks first. An extension's button, badge and popup appear in the tab strip. Chrome (.crx) extensions can't run in Gecko, so they are refused.
